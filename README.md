# Astro Postdoc Radar

European astronomy & astrophysics postdoc grants and positions, in one place.

## Development

```sh
npm install
npm run dev
```

Environment variables (see `.env`): `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`,
`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, plus server-only `FIRECRAWL_API_KEY`
and `DATABASE_URL` (for `drizzle-kit` migrations).
